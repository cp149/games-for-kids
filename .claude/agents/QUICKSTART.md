## 🔧 When to Use Individual Agents

Most of the time, let the **@game-director** handle everything.

Use individual agents only when you need specific expertise:

```
# Need just a design concept?
@game-designer Design a boss battle mechanic

# Need just visual assets?
@ui-ux-designer Create character sprites for a chef

# Need just optimization?
@performance-optimizer Profile and optimize this game

# Need just documentation?
@project-chronicler Document this week's progress
```

## 💡 Pro Tips

1. **Be clear about what you want**
   - Good: "Create a match-3 puzzle game for ages 6-10"
   - Bad: "Make a game"

2. **Provide context**
   - Mention target audience
   - Specify technical constraints
   - Share your vision

3. **Review at milestones**
   - The director will show you progress
   - Give feedback at each phase
   - Request changes before moving forward

4. **Trust the process**
   - The director follows proven workflows
   - Let specialists do their work
   - Quality takes time
