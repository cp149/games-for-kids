## 🎮 What We Built

Race against AI to solve Hamiltonian path puzzles (visit every dot exactly once). AI opponent powered by Ant Colony Optimization algorithm - the same technique used in real-world routing optimization.

**Core Features**:
- Ant Colony Optimization AI opponent (smart pathfinding)
- 15 levels: 3×3 to 6×6 grids with progressive difficulty
- Backtracking algorithm ensures every puzzle is solvable
- 5 original background music tracks, tab-aware auto-pause
- Full i18n support (EN/ZH/ES) with 189 translations

### 1. First Competitive Game
Series' first player vs AI racing mechanic. Real-time competition creates engaging "beat the computer" gameplay - natural learning through play, not tutorials.

## 💡 Key Takeaways


**OO Refactoring - Callback Pattern**: Refactored AIManager from tight coupling to callback decoupling. Follows SOLID principles, independently testable, clear responsibility boundaries. All tests passing.

**Growing Shared Library**: Extracted ParticleSystem from path-race, migrated match-three to use it. Code agents learning to identify reusable patterns and reduce duplication while maintaining clean architecture.

**Kids Don't Read Text**: Text-based feedback doesn't work for 5-8 year olds. Solution: Big emoji 🎉 + bounce animation + sound effect for game events. Visual + audio + animation > text descriptions.

**Architecture Principles**:
- Callback pattern > direct dependencies (DIP)
- Encapsulate methods > expose internals (Law of Demeter)
- Dependency injection > hardcoded deps (testability)
- Observe 3× before abstracting > premature optimization
