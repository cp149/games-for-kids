# Chemistry Lab - 用户指南 🧪

欢迎来到化学实验室！这是一款专为 6-10 岁儿童设计的化学反应益智游戏。

---

## 🎯 游戏目标

混合试剂卡片，创造五彩缤纷的化学反应，完成每个关卡的目标！

---

## 🕹️ 如何游戏

### 基础操作（3 种方式）

#### 🖱️ 鼠标操作（电脑）
1. **拖动卡片**: 点击并按住卡片，拖到实验槽
2. **放下卡片**: 松开鼠标，卡片掉入槽中
3. **混合**: 点击"混合 🧪"按钮触发反应

#### 👆 触摸操作（手机/平板）
1. **拖动卡片**: 手指按住卡片，拖到实验槽
2. **放下卡片**: 抬起手指，卡片掉入槽中
3. **混合**: 点击"混合 🧪"按钮

#### ⌨️ 键盘操作（无障碍）
1. **选择卡片**: 按 `Tab` 键切换卡片
2. **拖动卡片**: 按 `Enter` 或 `Space` 选中卡片
3. **放入槽位**: 使用方向键移动到槽位，按 `Enter` 放下
4. **混合**: `Tab` 到混合按钮，按 `Enter`

## 💥 化学反应表

### 基础反应（单色）

```
🔴 + 🔴 = 💥 红色爆炸 (+10 分)
🔵 + 🔵 = 💥 蓝色爆炸 (+10 分)
🟡 + 🟡 = 💥 黄色爆炸 (+10 分)
```

### 组合反应（双色）

```
🔴 + 🔵 = 💜💥 紫色爆炸 (+20 分)
🔴 + 🟡 = 🧡💥 橙色爆炸 (+20 分)
🔵 + 🟡 = 💚💥 绿色爆炸 (+20 分)
```

### 高级反应（三色）

```
🔴 + 🔵 + 🟡 = 🌈💥 彩虹爆炸 (+30 分)
```

### 催化剂加成

```
⭐ + 反应 = 分数 × 2
例如: ⭐ + (🔴 + 🔵) = 40 分 (原本 20 分)
```

## 📊 关卡指南

### 世界 1: 探索实验室（关卡 1-3）

#### 🧪 关卡 1: 初次反应
- **目标**: 完成 3 次反应
- **计时器**: 无限时间
- **难度**: ⭐ 简单
- **提示**: 随便拖卡片，按混合按钮！试试看会发生什么

#### 💜 关卡 2: 紫色科学
- **目标**: 制造 2 次紫色爆炸
- **计时器**: 无限时间
- **难度**: ⭐⭐ 简单
- **提示**: 紫色 = 红色 + 蓝色（💜 = 🔴 + 🔵）

#### ⏱️ 关卡 3: 速度实验室
- **目标**: 60 秒内完成 5 次反应
- **计时器**: 60 秒
- **难度**: ⭐⭐ 简单
- **提示**: 别犹豫！快速拖卡片和混合

---

### 世界 2: 催化剂室（关卡 4-6）

#### ⭐ 关卡 4: 催化剂之力
- **目标**: 使用催化剂 1 次
- **计时器**: 90 秒
- **难度**: ⭐⭐⭐ 中等
- **提示**:
  - 拖 ⭐ 到实验槽（不是试剂卡！）
  - 再拖试剂，混合时得分翻倍
  - 催化剂用完会返回，可以重复用

#### 📈 关卡 5: 增强反应
- **目标**: 获得 500 分
- **计时器**: 120 秒
- **难度**: ⭐⭐⭐ 中等
- **策略**:
  - 用催化剂加成组合反应（💜/🧡/💚）
  - 例如: ⭐ + (🔴 + 🔵) = 40 分
  - 优先做高分反应

#### 🏆 关卡 6: 催化剂大师
- **目标**: 90 秒内使用催化剂 5 次
- **计时器**: 90 秒
- **难度**: ⭐⭐⭐⭐ 困难
- **策略**:
  - 快速循环：放催化剂 → 放试剂 → 混合 → 重复
  - 不用追求高分，只要用满 5 次

---

### 世界 3: 稳定站（关卡 7-9）

#### ⏳ 关卡 7: 与时间赛跑
- **目标**: 90 秒内完成 5 次反应
- **计时器**: 90 秒
- **新机制**: 试剂卡片会过期！
  - 卡片右上角显示倒计时（10 秒）
  - 倒计时变橙色（5 秒）→ 红色（3 秒）
  - 0 秒后卡片消失
- **难度**: ⭐⭐⭐⭐ 困难
- **提示**:
  - 拖 🛡️ 到快过期的卡片上
  - 卡片会停止倒计时，右下角显示盾牌

#### 🌈 关卡 8: 彩虹挑战
- **目标**: 制造 1 次彩虹爆炸
- **计时器**: 120 秒
- **试剂过期**: 10 秒
- **难度**: ⭐⭐⭐⭐ 困难
- **策略**:
  - 彩虹需要 3 张卡: 🔴 + 🔵 + 🟡
  - 收集 3 张不同颜色的卡
  - 用稳定剂防止卡片过期
  - 3 张都齐了再混合

#### 💎 关卡 9: 终极大师
- **目标**: 获得 1000 分
- **计时器**: 120 秒
- **试剂过期**: 8 秒（更快！）
- **难度**: ⭐⭐⭐⭐⭐ 非常困难
- **策略**:
  - 同时使用催化剂和稳定剂
  - 优先做高分反应（彩虹 = 30 分 × 2 = 60 分）
  - 快速决策，别让卡片过期

## 🎓 游戏技巧

### 初学者技巧

1. **先观察，再行动**
   - 看看有哪些颜色的卡片
   - 想好要做什么反应

2. **从简单开始**
   - 单色反应（🔴+🔴）先练习
   - 熟悉拖拽操作

3. **听音效**
   - 成功反应有愉快的音效
   - 失败反应有不同的声音

### 进阶技巧

1. **催化剂策略**
   - 催化剂配组合反应（+20 分）最划算
   - 别浪费在单色反应（+10 分）上
   - 记住催化剂会返回，多用几次

2. **稳定剂使用**
   - 优先保护稀有颜色（凑彩虹时）
   - 别太早用，等倒计时快结束
   - 稳定剂用了就没了，省着点

3. **时间管理**
   - L7-9 要快速决策
   - 看到好组合立刻放入槽
   - 别等"完美时机"

### 高手技巧

1. **彩虹流**（L8-9）
   - 目标：只做彩虹反应（30 分 × 2 = 60 分）
   - 收集红蓝黄 3 色，全部稳定
   - 高风险高回报

2. **连锁反应**（L6）
   - 催化剂 → 混合 → 等返回 → 立刻再用
   - 练习快速循环，节省时间

3. **颜色记忆**
   - 记住下一张会掉落什么颜色
   - 提前规划槽位

## ❓ 常见问题

### Q: 为什么我的反应失败了？
**A**: 可能的原因：
- ❌ 槽中卡片太少（至少 2 张）
- ❌ 卡片组合不匹配（如 🔴 + 🟢）
- ❌ 槽中有过期的卡片

**解决方法**: 检查反应表，确保使用正确组合

---

### Q: 催化剂怎么用？
**A**:
1. 先拖 ⭐ 到实验槽（会变成金色边框）
2. 再拖试剂卡片（红蓝黄）
3. 点击混合
4. 得分翻倍 × 2
5. 催化剂会返回手牌，可以再用

**注意**: 催化剂不是试剂，不能单独混合！

---

### Q: 稳定剂和催化剂有什么区别？
**A**:

| 特性 | 催化剂 ⭐ | 稳定剂 🛡️ |
|------|----------|----------|
| 作用 | 反应得分翻倍 | 防止卡片过期 |
| 使用方式 | 放入实验槽 | 拖到卡片上 |
| 使用后 | 返回手牌（可重复用）| 消失（一次性） |
| 出现关卡 | L4-6 | L7-9 |

---

### Q: 卡片过期倒计时是什么？
**A**:
- 从 L7 开始，卡片有"保质期"
- 右上角数字显示剩余秒数
- 倒计时颜色变化：
  - ⚪ 白色（10-6 秒）- 安全
  - 🟠 橙色（5-3 秒）- 警告
  - 🔴 红色（2-0 秒）- 危险
- 到 0 秒卡片会消失

**解决方法**: 使用稳定剂 🛡️ 拖到卡片上

---

### Q: 怎样获得 3 颗星？
**A**: 每关标准不同：

| 关卡 | 3 星条件 |
|------|---------|
| L1 | 完成即可（自动 3 星）|
| L2 | 第一次尝试成功 |
| L3 | 45 秒内完成 |
| L4 | 使用催化剂 3 次 |
| L5 | 达到 600 分 |
| L6 | 75 秒内使用催化剂 5 次 |
| L7 | 不使用稳定剂完成 |
| L8 | 100 秒内完成 |
| L9 | 达到 1200 分 |

### Q: 游戏卡顿怎么办？
**A**:
1. 关闭其他浏览器标签页
2. 按 `Ctrl + Shift + I` 打开开发者工具
3. 查看左下角性能监视器（FPS/MS）
4. 如果 FPS < 30，刷新页面

---

### Q: 移动设备上拖拽不灵敏？
**A**:
- 确保使用单指拖拽
- 卡片拖到槽位中心再松开
- 如果还是不行，尝试使用键盘操作（Tab + Enter）

---

### Q: 声音不工作？
**A**:
1. 检查浏览器是否静音
2. 点击右上角 🎵 按钮确保音乐开启
3. 某些浏览器需要用户交互后才能播放音频（点击任意按钮）

---

### Q: 能跳关吗？
**A**:
- ❌ 不能跳关
- ✅ 必须按顺序完成 L1 → L2 → L3 ...
- 💡 获得 1 颗星以上即可解锁下一关（不需要 3 星）
