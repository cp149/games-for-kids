# 🎹 Magic Piano Factory ✨

A magical piano game designed for children aged 3-14, featuring colorful keys, stunning visual effects, and educational musical content.

## 🌟 Features

### 🎵 Core Gameplay
- **Full 88-Key Piano**: Complete piano range (A0-C8) with smooth scrolling navigation
- **Smart Navigation System**: Octave jumping buttons and position indicators
- **Three Play Modes**: 
  - 🎹 **Free Play**: Create music freely with immediate feedback
  - 🎶 **Songs**: Learn popular children's songs with visual guidance
  - 🎙️ **Recording**: Record and playback your musical creations

### ✨ Visual Magic
- **Particle Effects**: Musical notes and colorful particles on every key press
- **Key Animations**: Responsive visual feedback with color-coded keys
- **Magical Themes**: Space-themed background with gradient effects
- **Real-time Visual Response**: Immediate feedback for all interactions

### 🎼 Educational Content
- **Children's Songs Library**:
  - Twinkle, Twinkle, Little Star
  - Happy Birthday to You
  - Mary Had a Little Lamb
  - Row, Row, Row Your Boat
- **Progressive Difficulty**: Songs categorized by difficulty level
- **Practice Modes**: Rhythm practice and melody learning

### 🔊 Audio System
- **Web Audio API**: High-quality piano sounds with harmonics
- **Realistic Piano Tones**: Multiple harmonics for rich sound
- **ADSR Envelope**: Authentic piano attack, decay, sustain, release
- **Volume Control**: Master volume and mute functionality

### 📱 Responsive Design
- **Mobile-First**: Optimized for touch devices
- **Cross-Platform**: Works on phones, tablets, and desktop
- **Touch-Friendly**: Large keys suitable for small fingers
- **Adaptive Layout**: Keyboard scales to screen size

### 🎯 Accessibility
- **Child-Friendly UI**: Large buttons and clear visual hierarchy
- **Keyboard Support**: Computer keyboard can play piano keys
- **Visual Feedback**: Clear indication of pressed keys
- **Audio Cues**: Immediate sound feedback

## 🚀 Quick Start

1. **Open the Game**: Navigate to `index.html` in a web browser
2. **Allow Audio**: Click anywhere to enable audio (browser requirement)
3. **Start Playing**: 
   - Tap colorful piano keys to play notes
   - Use computer keyboard keys Q-P for notes
   - Switch modes using the top control panel

## 🎮 How to Play

### Free Play Mode 🎹
- Tap any piano key to play notes
- Watch magical particles appear with each note
- Create your own melodies and compositions
- Use keyboard shortcuts for faster playing

### Songs Mode 🎶
- Choose from 4 popular children's songs
- Follow visual cues to learn melodies
- Practice at your own pace
- Build musical confidence

### Recording Mode 🎙️
- Press any key to start recording automatically
- Play your melody while recording
- Use playback controls to listen to your creation
- Clear and re-record as many times as you want
