# Quick Start Guide - Animal Memory Match

## 🚀 Start Playing in 3 Steps

### Step 1: Open the Game
```bash
# Option A: Direct open (easiest)
open games/memory-match/index.html

# Option B: Using a web browser
# Just double-click index.html file

# Option C: Using a local server
cd games/memory-match
python -m http.server 8000
# Then visit: http://localhost:8000
```

### Step 2: Play
- Click any card to flip it
- Click another card to find the match
- Match all 6 pairs to win!

### Step 3: Enjoy!
- Switch languages with the dropdown (🇺🇸 EN ▼)
- Try to beat your previous score
- Have fun! 🎉
