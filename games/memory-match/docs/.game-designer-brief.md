# Game Designer Brief: Memory Match Game

## Assignment
Design a memory matching card game for children ages 3-8.

## Requirements
- Target audience: Children ages 3-8 (simple, intuitive gameplay)
- 12 cards total (6 pairs of cute animals)
- Animals: cat, dog, rabbit, panda, elephant, lion
- Click/tap to flip cards
- Match pairs to progress
- Track time and moves
- Win when all pairs matched

## Design Deliverables Needed
1. Core game mechanics (how flipping works, matching rules)
2. Win/loss conditions
3. Scoring system (time tracking, move counting)
4. Child-friendly interaction patterns
5. Difficulty considerations for age group
6. Accessibility features for young children

## Technical Constraints
- Single-page HTML game
- Touch-friendly (mobile + desktop)
- Large touch targets (minimum 80px cards)
- Simple, clear visual feedback
- No complex animations that confuse young children
