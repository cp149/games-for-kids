# Memory Matching Card Game Development Task

## Project Goal
Create a complete memory matching card game for children aged 3-8.

## Requirements
- 12 cards (6 pairs of cute animals: Cat, Dog, Rabbit, Panda, Elephant, Lion)
- Click to flip cards, match pairs to win
- Track time and number of moves
- Multi-language support (Chinese, English, Japanese) using i18n
- Child-friendly design with cute animations
- Responsive design (mobile + desktop)
- Pure HTML/CSS/JavaScript (single file acceptable)
- 60 FPS smooth animations
- No console.logs in production
- All code and comments in English

## Development Phases
1. Game Design & UI Design
2. Asset Creation (cute animal images)
3. Implementation (HTML/CSS/JS with i18n)
4. Testing & Bug Fixing
5. Performance Optimization
6. Documentation & Delivery
