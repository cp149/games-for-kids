# Music Factory - User Guide

## Welcome to Music Factory! 🎵

Create your own amazing music by building with colorful sound blocks!

---

## Getting Started

### Step 1: Start the Game

1. Open Music Factory in your browser
2. Click the big **"Start Creating"** button
3. Wait a few seconds while the music blocks load
4. You're ready to make music!

### Step 2: Explore the Interface

**Left Side - Block Library**
- This is where all your music blocks live
- Each block is a small piece of music
- Blocks are organized by type (Drums, Bass, Melody, Effects)

**Right Side - Timeline**
- This is where you build your song
- 4 tracks, one for each type of music
- Drag blocks here to create music

**Top - Control Buttons**
- Play, Stop, Save, Load, and Clear buttons

---

## How to Make Music

### Basic Steps

1. **Choose a Block**
   - Look at the Block Library on the left
   - Find a block you want to try

2. **Preview the Sound**
   - Click on any block to hear what it sounds like
   - Try different blocks to find ones you like

3. **Drag to Timeline**
   - Click and hold a block
   - Drag it to the timeline on the right
   - Drop it on a track (same color)

4. **Play Your Music**
   - Click the **Play ▶** button at the top
   - Listen to your creation!

5. **Keep Building**
   - Add more blocks to make it longer
   - Stack different tracks for richer sound
   - Experiment and have fun!

## Understanding Tracks

### 🥁 Drums Track (Red/Orange)
- **What it is:** Beat and rhythm
- **Use it for:** The backbone of your song
- **Tip:** Start with drums first!

### 🎸 Bass Track (Blue)
- **What it is:** Deep, low sounds
- **Use it for:** Groovy foundation
- **Tip:** Bass goes great with drums

### 🎹 Melody Track (Yellow)
- **What it is:** Main tune
- **Use it for:** The catchy part everyone remembers
- **Tip:** This is the star of your song

### ✨ FX Track (Pink)
- **What it is:** Special effects
- **Use it for:** Sparkles and surprises
- **Tip:** Use sparingly for accent

## Block Types

Each block has:
- **Name** - What the block is called
- **Mood Emoji** - How the block feels
  - 😊 Happy - Cheerful sounds
  - 🎉 Energetic - Fast and exciting
  - 😌 Calm - Peaceful sounds
  - 🎃 Mysterious - Quirky and unusual
- **Duration** - How long it lasts (4 or 8 beats)

## Tips for Great Music

### For Beginners

1. **Start Simple**
   - Use just 2-3 blocks at first
   - Get comfortable with the basics

2. **Follow the Grid**
   - Blocks snap to the grid automatically
   - This keeps your music in time

3. **Match the Moods**
   - Put happy blocks together
   - Or mix moods for interesting effects

4. **Use Your Ears**
   - If it sounds good, it IS good
   - Trust what you hear

### For Advanced Creators

1. **Layer Your Tracks**
   - Use all 4 tracks for full sound
   - Start with drums, add bass, then melody

2. **Create Patterns**
   - Repeat blocks to create rhythm
   - Leave gaps for dynamics

3. **Build Sections**
   - Intro (simple)
   - Verse (add more)
   - Chorus (everything!)
   - Ending (fade out)

4. **Experiment with Combinations**
   - Try unexpected pairings
   - Happy drums + mysterious melody = interesting!

## Using the Controls

### Play / Pause Button
- **First click:** Start playing your song
- **While playing:** Pause (you can resume later)
- **When paused:** Resume from where you stopped

### Stop Button
- Stops the music completely
- Returns to the beginning
- Use this to start over fresh

### Clear Button
- Removes ALL blocks from the timeline
- Warning: This can't be undone!
- But your blocks are still in the library

### Save Button
- Saves your composition
- You'll be asked to name it
- Saves to your browser (works offline!)

### Load Button
- Load a previously saved composition
- Type the name you used when saving
- Your composition comes back!

### Loop Checkbox
- When ON: Your song repeats automatically
- When OFF: Plays once and stops
- Great for testing your creation

### Volume Slider
- Move right: Louder
- Move left: Quieter
- Adjust to comfortable level

## Advanced Features

### Moving Blocks

Already placed a block but want to move it?

1. Click and drag the block on the timeline
2. Move it to a new position
3. Drop it where you want
4. The block moves to the new spot!

### Removing Blocks

Don't like a block anymore?

1. Find the block on the timeline
2. Look for the **×** button on the block
3. Click the × button
4. The block disappears (but stays in library)

### Using the Same Block Multiple Times

Want to repeat a block?

1. You can drag the same block from the library many times
2. Each copy is independent
3. Build patterns by repeating blocks
4. Great for creating rhythm!

## Common Questions

### Why can't I place a block?

**Possible reasons:**
- Another block is already there (blocks can't overlap)
- You're trying to place it outside the timeline
- Make sure you're dropping on the correct track

**Solution:**
- Move existing blocks out of the way
- Try a different position
- Drop on a different track

### How long can my song be?

- Maximum 32 beats (about 16 seconds)
- But you can use the Loop feature to repeat it!
- This keeps the game running smoothly

### Where are my saves stored?

- In your browser's local storage
- Saves are tied to this browser
- If you clear browser data, saves are lost
- So keep creating new ones!

### Can I export my music?

- Not yet, but coming soon!
- For now, you can play and share live
- Or record your screen with audio

## Troubleshooting

### No sound playing?

1. Check your device volume
2. Check the volume slider in the game
3. Make sure you have blocks on the timeline
4. Try refreshing the page

### Blocks not loading?

1. Wait a bit longer (large files take time)
2. Check your internet connection
3. Try refreshing the page
4. Clear browser cache and try again

### Drag and drop not working?

1. Make sure you're clicking and holding
2. Try using a mouse instead of trackpad
3. Check if your browser supports drag and drop
4. Try a different browser (Chrome recommended)
