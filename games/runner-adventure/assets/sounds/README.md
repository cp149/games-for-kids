# Background Music

Please generate the background music using this prompt:

```
Create a cheerful, upbeat background music track for a casual runner game. Bright and bouncy melody with a playful cartoon style. Tempo around 140 BPM. Instruments: light piano, xylophone, ukulele, and light percussion. Perfect for looping. Duration: 1-2 minutes. Fun, energetic, suitable for all ages. No vocals.
```

Save the generated music file as `background-music.mp3` in this directory.

## Sound Effects

The game uses Web Audio API to generate sound effects dynamically:
- Jump sound: Quick rising tone (400Hz → 600Hz)
- Coin collection: Bright chime (800Hz → 1200Hz)
- Game over: Descending tone (400Hz → 100Hz)

No additional audio files needed for sound effects!
