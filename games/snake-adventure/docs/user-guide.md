# Snake Adventure - User Guide

## 🎮 How to Play

### Objective
Control a glowing neon snake, collect golden food orbs to grow longer and score points. Avoid hitting the walls or your own body!

### Getting Started

1. **Open the game** in your web browser
2. **Choose language** (if needed) - auto-detected from browser
3. **Press SPACE** (keyboard) or **TAP** (mobile) to start
4. **Guide your snake** to collect food and grow!

## 🕹️ Controls

### Desktop (Keyboard)
- **Arrow Keys** (← → ↑ ↓): Steer your snake in any direction
  - **Left/Right**: Turn the snake smoothly
  - **Up/Down**: Adjust vertical direction
- **SPACE**: Pause/Resume game or Start from menu
- **R Key**: Restart after game over

### Mobile (Touch)
- **Swipe anywhere**: Change snake direction
  - Swipe left → Snake turns left
  - Swipe right → Snake turns right
  - Swipe up → Snake moves up
  - Swipe down → Snake moves down
- **Pause Button** (⏸ top-right): Pause/Resume
- **Tap screen**: Start game from menu

### Tips for Touch Controls
- Use **short swipes** for quick direction changes
- **Continuous swiping** for smooth navigation
- The snake always moves forward - you just change direction!

## 📊 Scoring

### Points
- **Food Collection**: +10 points per golden orb
- **No time penalty**: Take your time to strategize!

### Progression
As you collect food, your snake will:
1. **Grow Longer**: One segment per food
2. **Move Faster**: Speed increases at milestones
   - After 10 food: Speed up!
   - After 25 food: Faster!
   - After 50 food: Even faster!
   - After 100 food: Maximum speed!

### Achievement Milestones
Get special notifications when reaching:
- 🏆 **20 segments**: "You're getting good!"
- 🏆 **50 segments**: "Amazing length!"
- 🏆 **100 segments**: "Snake master!"
- 🏆 **200 segments**: "Legendary!"
- 🏆 **500 segments**: "Ultimate champion!"

## 🎯 Strategy Tips

### For Beginners
1. **Start slow**: Don't rush - take your time to learn controls
2. **Stay centered**: Avoid edges when starting out
3. **Make wide turns**: Easier to avoid your tail
4. **Plan ahead**: Look where food will spawn

### Advanced Techniques
1. **Spiral pattern**: Efficient for long snakes
2. **Wall riding**: Use edges strategically for tight spaces
3. **Quick reflexes**: At high speeds, react fast to avoid yourself
4. **Food anticipation**: Predict spawn locations

### Survival Tips
- **Watch your tail**: Longer snake = more danger
- **Avoid corners**: Getting trapped is common
- **Speed management**: Faster isn't always better
- **Calm gameplay**: Don't panic when long!

## 🐛 Troubleshooting

### Game Not Loading
- **Check browser**: Use Chrome, Firefox, Safari, or Edge
- **Enable JavaScript**: Required for game to run
- **Clear cache**: Refresh page with Ctrl+F5

### Performance Issues
- **Close other tabs**: Free up browser memory
- **Reduce effects**: If settings available
- **Update browser**: Latest version recommended

### Controls Not Working
- **Keyboard**: Click game area first to focus
- **Touch**: Ensure screen is clean and responsive
- **Refresh**: Reload page if controls stuck

### Visual Glitches
- **Update graphics drivers**: For desktop
- **Hardware acceleration**: Enable in browser settings
- **Different browser**: Try alternative browser

## 📚 Game Mechanics

### Physics
- **Smooth turning**: 360-degree movement (not grid-based)
- **Constant speed**: Always moving forward
- **Camera follow**: Viewport tracks your snake
- **Collision**: Circle-based (head, body, food)

### Spawning
- **Food appears**: Random safe locations
- **Safe distance**: Not too close to snake
- **Instant spawn**: Immediate after collection
- **One at a time**: Focus on current food
